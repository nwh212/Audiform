Audiform Theme Maker

About this theme

A theme is one file. Save it, then put it in Audiform's Themes folder (Edit > Settings > Appearance > Open Themes Folder) and choose Look Again.

Pictures and fonts

Window background: a picture behind the panels. Any size works: big pictures are shrunk to 2560 pixels across so the theme stays small, and the fit below decides what happens when the picture's shape is not the window's. Panels cover it unless you make them see-through.

Fonts: a WOFF2, WOFF, TTF or OTF file becomes the interface font (and the mono font if you tick it). Only fonts you may redistribute.

Mouse pointers

PNG pictures. Audiform draws pointers at 16 by 16 pixels, so any other size is scaled to that when you pick it (and the hot spot with it). The hot spot is the point that does the pointing, in pixels from the top left, 0 to 15. Kinds left out keep the standard pointer.

Extra style sheet (advanced)

Any CSS, applied when the theme is on. Rules are written for you against :root[data-theme="your-id"] when they do not start with it. Pictures go in as assets and are used with url(asset:name). No @import and no web addresses: Audiform refuses them.

    Views that draw themselves

    Share your theme by sharing the file. The Audiform repository on GitHub has a Themes discussion where people post theirs with a screenshot.
